## Sobre este repositório

Este repositório contém o HTML, CSS e JS estático publicados pelo GitHub Pages, gerado a partir de um repositório-fonte Hugo mantido em separado. A cada novo post, um workflow de CI builda o site no repositório-fonte e publica o resultado aqui automaticamente.

É um padrão comum para blogs estáticos com build customizado no GitHub Pages: quando o gerador precisa de passos que o Pages não builda nativamente (nesse caso, Hugo Extended e um tema vendorizado como submódulo), o código-fonte fica em um repositório separado e este aqui serve só como saída de deploy. Por isso o histórico de commits reflete deploys, não o desenvolvimento do conteúdo. Para falar sobre o texto dos posts, use os canais de contato mais abaixo.

> O conteúdo do blog é majoritariamente em português (pt-BR). Existe uma seção em inglês configurada em `/en/`, ainda sem posts traduzidos.

## Sobre o blog

Blog pessoal sobre Data Science, Machine Learning, Python, R e Inteligência Artificial. Tutoriais práticos, projetos reais e insights de um Kaggle Master com experiência corporativa.

Sou formado em estatística e atuo como cientista de dados desde 2017, hoje como Data Science Specialist na Accenture. Compartilho aqui os estudos, experimentos e projetos de código aberto que faço fora do trabalho.
